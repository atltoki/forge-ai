## Tables and safety properties

- `orbit_priority_sets`: singleton personal register, revision and timestamp.
- `orbit_priorities`: stable IDs, title, status, position, timestamps,
  and reversible deletion markers.
- `orbit_priority_events`: append-only history and unique revision.
- SQLite triggers reject outdated revisions, unaudited changes, hard deletes
  and event rewrites. Future write implementations must use atomic D1.batch().
- An empty `GET` result **must never clear browser storage**.
