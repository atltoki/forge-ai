# Changelog

## V0.2 - Agent OS foundation

- Ajout des routes Tools, Logs, Analytics et Auth.
- Ajout d un modele de domaine TypeScript pour agents, missions, tools, mémoire, logs et executions.
- Ajout des engines internes : Agent Engine, Mission Engine, Tool Manager et Memory Engine.
- Extension du schema Supabase avec users, agents, missions, memory, tools, logs et executions.
- Ajout d endpoints API pour agents, tools, mission planning, missions et auth status.
- Mise a jour du cockpit Dashboard pour afficher orchestration, tools, executions et activite systeme.
